# Sathi Midya: Product Designer Portfolio

Built with **Next.js 15** (App Router), **Tailwind CSS v4** and **shadcn/ui**.

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000

## Where things live
- `src/lib/content.ts`: all text content (intro, case studies, experience, skills, testimonials). Edit here to change copy.
- `src/components/site/`: one component per page section (hero, about, case studies, …)
- `src/components/ui/`: shadcn/ui components (button, card, badge, separator, sonner)
- `src/app/globals.css`: color palette and theme tokens
- `public/`: photo and resume
